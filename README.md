# wves. — Cinematic Developer Portfolio

> **ODDIYLIKDAN TASHQARI RAQAMLI TAJRIBALAR.**  
> *Crafting unexpected digital experiences with intention, motion, and precision.*

A modern, high-performance developer portfolio built with Next.js 15, React 19, TypeScript, Tailwind CSS, Three.js, and GSAP. Features cinematic interactive project exploration, realistic cosmic particle canvas, full 3-language internationalization (English, Russian, Uzbek Latin), and zero layout shifts.

---

## ✨ Features

- **Cinematic Experience & Visuals:**
  - Dynamic 3D kinetic text reveals with blur and perspective transforms.
  - Custom canvas simulation of a realistic starry night sky with twinkling stars, falling meteors with persistent glowing trails, and gentle mouse parallax.
  - Interactive custom mockups for all featured projects with telemetry, equalizer, radar, and terminal interfaces.
  - Custom neon halo cursor and responsive glowing accents.

- **Interactive Project Explorer:**
  - Integrated in-browser live preview modal supporting responsive viewport switching (Desktop 1920×1080 / Mobile 375×812), fullscreen mode, and direct external navigation.
  - Dedicated deep-dive project pages (`/projects/[slug]`) with animated navigation.

- **Full Trilingual Localization (EN / RU / UZ):**
  - Seamless switching between English, Russian, and Uzbek (Latin script).
  - Fully translated navigation, dossiers, project descriptions, educational milestones, and CTAs.
  - Language selection persisted via `localStorage`.

- **Comprehensive Developer Dossier:**
  - Mars IT School educational timeline (Frontend Development & Frontend Pro).
  - Interactive dossier tabs for core tech stack, engineering standards, and modular workflow.

## 🛠 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19)

## 💻 Getting Started

### Prerequisites
- Node.js 18.17+ or 20+
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/wves-cpu/wves-portfolio.git

# Navigate into project directory
cd wves-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the portfolio.

### Production Build

```bash
npm run build
npm run start
```
